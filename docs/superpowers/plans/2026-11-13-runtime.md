# gositter-rs runtime implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the gositter v0.2.0 (7a27b30) runtime to safe Rust so that all 1,423 C-made goldens in `testdata/regress` pass on amd64 and arm64, and a pure-Go gositter dump tool agrees with ours byte for byte (trees, LOG lines, stall counts).

**Architecture:** One Cargo workspace. The root package `gositter` is the runtime, one Rust file per gositter Go file, function for function. `src/api.rs` is the frozen contract with the grammar stream (Task 1). `treedump/` ports gositter's `internal/treedump`. The gositter tests that need a grammar, the regress runner and the `gsdump` example (the Rust side of the parity and bench stages) live in the root package's `tests/` and `examples/`, with `gositter-grammars` and `gositter-treedump` as dev-dependencies. A pure-Go `gsdump`, built in CI inside a copy of the gositter v0.2.0 module, is the oracle.

**Tech Stack:** Rust 1.99.1, edition 2024, std only. CI on ARC with in-cluster BuildKit (`ci/Dockerfile`), Go 1.27 for the oracle stages only, cargo-fuzz on nightly in `fuzz/` (Decision D3).

**Spec:** graphify-rs `docs/superpowers/specs/2026-11-12-graphify-rs-design.md` (sections 2, 3 "gositter-rs", 7, 12) and the master plan `docs/superpowers/plans/2026-11-12-graphify-rs-master.md` (Global Constraints, Task 4). Behaviour source: gositter v0.2.0 `CONTRACT.md`, which this plan keeps: C-exact trees, byte-identical LOG lines, deterministic stall count. Companion plan: `docs/superpowers/plans/2026-11-13-grammars.md` (grammar stream, PR #2).

- GitHub API: shared 5,000/hr. No `gh` polling loops; use the T3 PR watch tools.
- Shared files (`Cargo.toml`, `ci/Dockerfile`, `.github/workflows/ci.yml`, `parity/README.md`): small separate commits, rebased on main before each push, as the grammar stream does.
- Porting rules (from gositter CONTRACT.md §2 and §11, applied to Rust):
  - One Rust file per gositter Go file, same basename (`parser.go` -> `src/parser.rs`).
  - Above every ported function, the comment line of the Go source (`// ts_parser__lex`, or the Go name for a gositter-only function).
  - Names: the Go name in snake_case (`doAllPotentialReductions` -> `do_all_potential_reductions`); Go types in UpperCamel (`subtreeHeap` -> `SubtreeHeap`). Constants keep the Go value, in SCREAMING_SNAKE (`maxVersionCount` -> `MAX_VERSION_COUNT = 6`).
  - Same control flow, iteration order, tie-breaks, constants and unsigned wrap-around as Go (`wrapping_*` where Go relies on wrap, for example `condenseStack` i/j and `lookaheadSymbol+1`).
  - Port gositter's fast paths as written (`reduceInPlace`, `summarizeTwoHeap`, `summarizeOneChild`, summary resume, `fHasRepeat`, the children block allocator, the comb small table, `reduceScans`/`missingScans` caches). Each one already has a Go differential test, which this plan ports.
  - Do not port the Go GC workarounds: all of `slabpool.go` (weak and strong shared free lists, `keep`/`age`, 1024-parse and 32 MiB holds), the `heapChunks` `sync.Pool`, `childSlabs` weak pools, `outgrown`, `warm`, `moveChildren` weak handling, `nodesBox`/`linksBox`/`nodesOut`/`linksOut`, `reserveHeap`. Replace them with per-parser `Vec`s that a reset truncates and keeps, plus the gositter shrink rule: at reset, a slab above its limit (children `1<<16`, stack nodes `1<<14`, links `1<<12`, index slabs `1<<20` entries) that the parse before used under an eighth of is shrunk to its initial size; heap chunks beyond `KEPT_HEAP_CHUNKS = 8` are dropped.
  - Go maps keyed by `(language, state)` become `Vec`s indexed by state, cleared by `set_language`. No map iteration may reach output.

## Review Focus

1. **`kind_mask` called while other threads parse** (graphify `javascript.go:49,163` call `KindMask` inside `extractJS` on worker goroutines). Expected: a name already registered returns the same mask from any thread, with only Relaxed atomic loads on the parse path; a new name registers safely; a tree parsed before a name was registered carries no bit for it; the 33rd distinct name panics with `gositter: more than 32 kinds named to KindMask`. Tests: Task 7 `kind_mask_threads`, Task 11 `kind_mask_after_parse`.
2. **Deep trees on Rust's fixed thread stacks.** Go stacks grow; Rust test threads have 2 MiB. Go recurses in `preorderChildren`, `appendChildren`, `childWithDescendant`, `ChildByFieldID`, `nodeRelease`, `nodeAddLink`, `writeToString` and treedump `visit`. Expected: `preorder`, `preorder_mask` and `children` never overflow on a 100,000-deep tree on a 512 KiB stack. Test: Task 10 `preorder_deep_small_stack`. treedump and the regress runner run each case on a thread with a 1 GiB stack (reserved, not committed).
3. **Go `%q` quoting in treedump.** Kind names include `"\""`, `"\\"`, `'\0'` UNEXPECTED leaves and verilog's printable non-ASCII `–>`, `–`, `––`, `[–>`. Expected: byte-identical to Go `strconv.Quote` for every kind name of the 21 grammars. Test: Task 3 `go_quote_cases`; Task 12 diffs `gsdump kinds` of both tools.
4. **Stall count equals Go's, not just "deterministic".** graphify's `OverBudget` flag depends on the exact count. Expected: for every regress input up to 8 KiB, the smallest `max_stall` that lets `parse_budget` finish is the same number in Rust and Go, for fresh, reused and stopped parsers. Tests: Task 11 `parse_budget_*_json`; Task 12 `gsdump stall` diff.
5. **char signedness on linux/arm64.** The C goldens were made on darwin (signed `char`); gositter's `cchar` is unsigned on linux/arm64, so the bash, ruby and hcl scanners can give a different tree there. Expected: on arm64, Rust equals Go-arm64 on every input. Where a C golden differs from Go-arm64, the Go-arm64 dump is the reference and the case is listed in `parity/README.md`. Test: Task 12 `parity-arm64` stage; Task 15 applies the rule.

## The interface (src/api.rs), frozen by Task 1

The grammar stream codes to this. A change after Task 1 merges needs a dated entry in `docs/CONTRACT_CHANGES.md` and a message to both streams through the coordinator.

```rust
pub type Symbol = u16;
pub type StateId = u16;
pub type FieldId = u16;

pub const SYMBOL_END: Symbol = 0;
pub const SYMBOL_ERROR: Symbol = 0xFFFF;
pub const SYMBOL_ERROR_REPEAT: Symbol = 0xFFFE;
pub const SERIALIZATION_BUFFER_SIZE: usize = 1024;
pub const TREE_SITTER_LANGUAGE_VERSION: u32 = 15;
pub const MIN_COMPATIBLE_LANGUAGE_VERSION: u32 = 13;
pub const LANGUAGE_VERSION_WITH_RESERVED_WORDS: u32 = 15;
pub const LANGUAGE_VERSION_WITH_PRIMARY_STATES: u32 = 14;

// Elements. All derive Clone, Copy, Debug, Default, PartialEq, Eq.
pub struct Point { pub row: u32, pub column: u32 }            // column counts bytes
pub struct FieldMapEntry { pub field_id: FieldId, pub child_index: u8, pub inherited: bool }
pub struct MapSlice { pub index: u16, pub length: u16 }
pub struct SymbolMetadata { pub visible: bool, pub named: bool, pub supertype: bool }
pub struct LexMode { pub lex_state: u16, pub external_lex_state: u16, pub reserved_word_set_id: u16 }
pub struct CharacterRange { pub start: i32, pub end: i32 }   // inclusive
pub struct LanguageMetadata { pub major_version: u8, pub minor_version: u8, pub patch_version: u8 }
/// One 8-byte slot of the parse actions (gositter CONTRACT.md §4).
pub struct ParseAction {
    pub action_type: u8,          // Go `Type`; header slot: entry.count
    pub child_count: u8,          // header slot: entry.reusable (0/1)
    pub symbol: Symbol,           // shift slot: state
    pub dynamic_precedence: i16,  // shift slot: bit 0 extra, bit 1 repetition
    pub production_id: u16,
}
pub const PARSE_ACTION_TYPE_SHIFT: u8 = 0;
pub const PARSE_ACTION_TYPE_REDUCE: u8 = 1;
pub const PARSE_ACTION_TYPE_ACCEPT: u8 = 2;
pub const PARSE_ACTION_TYPE_RECOVER: u8 = 3;
impl ParseAction {
    pub const fn count(self) -> u8;        // header: action_type
    pub const fn reusable(self) -> bool;   // header: child_count != 0
    pub const fn state(self) -> StateId;   // shift: symbol
    pub const fn extra(self) -> bool;      // shift: dynamic_precedence & 1
    pub const fn repetition(self) -> bool; // shift: dynamic_precedence & 2
}

// Views (D4). Each is `#[derive(Clone, Copy, Debug)] pub struct X(&'static [u8]);` with
//   pub const fn new(bytes: &'static [u8]) -> Self;   // panics if len % size != 0
//   pub const fn at(blob: &'static [u8], offset: usize, count: usize) -> Self; // blob[offset..offset+count*size]
//   pub const EMPTY: Self;
//   pub const fn len(self) -> usize;
//   pub fn get(self, i: usize) -> Element;            // panics if i >= len
// Byte layout = grammars plan Task 4 table, all little-endian:
pub struct U16s;            // u16, 2 B
pub struct U32s;            // u32, 4 B
pub struct Bools;           // bool, 1 B (0 or 1; other values panic in get)
pub struct ParseActions;    // ParseAction, 8 B: action_type, child_count, symbol, dynamic_precedence, production_id
pub struct LexModes;        // LexMode, 6 B: lex_state, external_lex_state, reserved_word_set_id
pub struct SymbolMetadatas; // SymbolMetadata, 1 B: bit 0 visible, bit 1 named, bit 2 supertype
pub struct MapSlices;       // MapSlice, 4 B: index, length
pub struct FieldMapEntries; // FieldMapEntry, 4 B: field_id u16, child_index u8, inherited u8
/// For hand-written tables (tests, the D8 fixture): `static B: [u8; 6] = le_bytes::<3, 6>(&[1, 2, 3]);`
/// panics when M != 2 * N.
pub const fn le_bytes<const N: usize, const M: usize>(v: &[u16; N]) -> [u8; M];

/// A generated ts_lex / ts_lex_keywords wrapper (D5).
pub type LexFn = fn(&mut Lexer<'_>, StateId) -> bool;

/// One instance of a grammar's external scanner (gositter CONTRACT.md §7, D6).
pub trait ExternalScanner: Send {
    /// valid_symbols has external_token_count entries. On success set
    /// lexer.result_symbol to the external token index.
    fn scan(&mut self, lexer: &mut Lexer<'_>, valid_symbols: &[bool]) -> bool;
    /// Returns the bytes written. Byte-identical to C.
    fn serialize(&self, buf: &mut [u8; SERIALIZATION_BUFFER_SIZE]) -> usize;
    /// buf.is_empty() is the C (NULL, 0) reset.
    fn deserialize(&mut self, buf: &[u8]);
    /// Go's optional Reset(): put the scanner in exactly the state the
    /// constructor returns and return true; false (default) makes the parser
    /// call the constructor.
    fn reset(&mut self) -> bool { false }
}

#[derive(Clone, Copy)]
pub struct ExternalScannerInfo {
    pub states: Bools,                // [external state][external_token_count], row 0 unused
    pub symbol_map: U16s,
    pub create: Option<fn() -> Box<dyn ExternalScanner>>, // None: no scanner
}

/// TSLanguage (ABI 15) field for field, C order; two-dimensional C arrays
/// flattened row-major. Every gositter CONTRACT.md §3 generator rule applies
/// (gaps kept, (uint16_t)-1 is 0xFFFF, name always set, missing fields
/// zero/EMPTY/None). Names must be valid UTF-8; gengrammar fails otherwise.
#[derive(Clone, Copy)]
pub struct LanguageTables {
    pub abi_version: u32,
    pub symbol_count: u32,
    pub alias_count: u32,
    pub token_count: u32,
    pub external_token_count: u32,
    pub state_count: u32,
    pub large_state_count: u32,
    pub production_id_count: u32,
    pub field_count: u32,
    pub max_alias_sequence_length: u16,
    pub parse_table: U16s,                     // [large_state_count][symbol_count]
    pub small_parse_table: U16s,
    pub small_parse_table_map: U32s,           // index by state - large_state_count
    pub parse_actions: ParseActions,
    pub symbol_names: &'static [&'static str], // symbol_count + alias_count
    pub field_names: &'static [&'static str],  // field_count + 1, [0] == ""
    pub field_map_slices: MapSlices,
    pub field_map_entries: FieldMapEntries,
    pub symbol_metadata: SymbolMetadatas,
    pub public_symbol_map: U16s,
    pub alias_map: U16s,                       // zero-terminated
    pub alias_sequences: U16s,                 // [production_id_count][max_alias_sequence_length]
    pub lex_modes: LexModes,                   // state_count
    pub lex_fn: LexFn,
    pub keyword_lex_fn: Option<LexFn>,
    pub keyword_capture_token: Symbol,
    pub external_scanner: ExternalScannerInfo,
    pub primary_state_ids: U16s,               // state_count
    pub name: &'static str,
    pub reserved_words: U16s,                  // [set][max_reserved_word_set_size]
    pub max_reserved_word_set_size: u16,
    pub supertype_count: u32,
    pub supertype_symbols: U16s,
    pub supertype_map_slices: MapSlices,
    pub supertype_map_entries: U16s,
    pub metadata: LanguageMetadata,
}

/// The tables plus the runtime's derived state (comb table, field-id cache,
/// KindMask bits). Sync, so a grammar holds it in a `static`:
///   static LANGUAGE: Language = Language::new(LanguageTables { .. });
///   pub fn language() -> &'static Language { &LANGUAGE }
/// Clone copies `tables` and starts fresh derived state (D7).
pub struct Language { pub tables: LanguageTables, /* private derived state */ }
impl Language {
    pub const fn new(tables: LanguageTables) -> Language;
    pub fn symbol_name(&self, s: Symbol) -> Option<&'static str>; // "ERROR", "_ERROR" for the builtins
    pub fn field_name_for_id(&self, id: FieldId) -> Option<&'static str>;
    pub fn field_id_for_name(&self, name: &str) -> FieldId;        // 0: none
    /// Next of 32 bits per new name; panics "gositter: more than 32 kinds named to KindMask".
    pub fn kind_mask(&self, kinds: &[&str]) -> u32;
}

/// The C Lexer with its TSLexer, valid for one parse ('s borrows the source).
/// Generated lexers and scanners use only the two public fields and these methods.
pub struct Lexer<'s> { pub lookahead: i32, pub result_symbol: Symbol, /* private */ }
impl Lexer<'_> {
    pub fn advance(&mut self, skip: bool);
    pub fn advance_run(&mut self, set: &'static [bool; 256], skip: bool); // CONTRACT.md §6
    pub fn mark_end(&mut self);
    pub fn get_column(&mut self) -> u32;
    pub fn is_at_included_range_start(&self) -> bool;
    pub fn eof(&self) -> bool;
}
pub fn set_contains(ranges: &[CharacterRange], lookahead: i32) -> bool;
/// ascii[c] == set_contains(ranges, c) for c < 128, precomputed by gengrammar.
pub fn set_contains_ascii(ascii: &[bool; 128], ranges: &[CharacterRange], lookahead: i32) -> bool;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LogType { Parse = 0, Lex = 1 }
/// Messages are bytes: C cuts them at 1,023 bytes, which can split a UTF-8 character.
pub type Logger = Box<dyn FnMut(LogType, &[u8]) + Send>;
```

`set_contains` and the run-set tables may also live in `gositter-grammars::lex` (their plan); the runtime keeps its own because CONTRACT.md §6 puts them in the runtime. C `char` signedness in scanners is the grammar stream's (`cchar`).

## Public API (src/tree.rs, node.rs, tree_cursor.rs, parser.rs), stubbed by Task 1

Go's null node is `None`. The `Tree` lives in the `Parser` and owns the subtree pool, as Go's `p.tree` holds `*subtreePool` (`parser.go:1842`).

```rust
pub struct Parser { /* lexer state, stack, tree: Tree, ... */ }   // Send
impl Default for Parser { fn default() -> Self { Parser::new() } }
impl Parser {
    pub fn new() -> Parser;                                                         // NewParser
    pub fn set_language(&mut self, l: &'static Language) -> Result<(), LanguageError>;
    pub fn set_logger(&mut self, logger: Option<Logger>);
    pub fn reset(&mut self);
    pub fn parse(&mut self, src: &[u8]) -> Option<&Tree>;                       // None: no language
    pub fn parse_budget(&mut self, src: &[u8], max_stall: u32) -> Option<&Tree>; // None: no language or stalled
}
/// Display: "gositter: incompatible language ABI version <n>".
#[derive(Debug, Clone, PartialEq, Eq)] pub struct LanguageError { pub abi_version: u32 }

/// Owns the pool; nodes borrow it until the next parse/reset/set_language (enforced by the borrow).
pub struct Tree { /* pool: SubtreePool, language, root slot */ }
impl Tree {
    pub fn root_node(&self) -> Node<'_>;
    pub fn language(&self) -> &'static Language;
}

/// Go's {tree, id, x, y}. PartialEq is Go `==`: std::ptr::eq on the tree, then id, x, y.
#[derive(Clone, Copy)] pub struct Node<'t> { /* tree: &'t Tree, id: u32, x: u64, y: u64 */ }
impl<'t> Node<'t> {
```

The lexer between parses: the `Parser` holds a `LexerState` (gositter `lexerState` fields without `src`, plus the logger and the debug buffer). Each parse moves it into a `Lexer<'s> { src, state }` on the stack and moves it back on every return path. `reset`, `set_logger` and parser logging outside a parse use the `LexerState` in the `Parser`.

graphify's 20 adapter methods (`ggo/internal/ts/ts.go:26-77`) map as: IsNull -> `Option`, Kind, IsNamed, StartByte, EndByte, StartPosition (`.row`), ChildCount, NamedChildCount, Child, NamedChild, ChildByFieldName, FieldNameForChild, Parent, Equals -> `equals`, Utf8Text, Children, Preorder, PreorderMask, Walk, ChildrenByFieldName; `TreeCursor.Close` is `Drop`; `Tree.Close` has no Rust form.
